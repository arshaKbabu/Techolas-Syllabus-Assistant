# Techolas-Syllabus-Assistant
Project Title:

Techolas Syllabus Assistant: A Retrieval-Augmented Generation (RAG) Chatbot Using LangChain, LangGraph, ChromaDB, and Local Qwen2.5

Description

Developed an intelligent syllabus chatbot that answers student queries using Retrieval-Augmented Generation (RAG). The chatbot first searches a Techolas syllabus PDF stored in a Chroma vector database and, if the required information is unavailable, retrieves information from the Techolas website. The application is orchestrated using LangGraph, built with LangChain components, and runs entirely on a local Qwen2.5 language model without requiring API keys.
